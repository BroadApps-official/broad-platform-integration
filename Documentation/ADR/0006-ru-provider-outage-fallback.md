# ADR-0006: серверный RU-каталог при недоступном Adapty

Статус: принято. Дата: 2026-09-09. Версия: BroadMonetization 1.5.0.

## Проблема

Удалённое из App Store приложение может не получить продукты Adapty. Обязательный
положительный ответ Adapty закрывал серверную оплату именно в этом случае.
Ошибка getPaywallProducts также скрывала конфигурацию, уже полученную SDK.

## Решение

Отдельный подключаемый loader допускает backend при недоступном провайдере и
российском Storefront **или** регионе iPhone. Полученный запрет имеет приоритет;
отсутствие ответа не равно отсутствующему полю. Нет автоматического ru_pay=true,
постоянного разрешения, нового источника Apple products или вымышленного эксперимента.

[Полный контракт и API](../RUProviderFallback.md). Этот ADR заменяет запрет host
fallback в ADR-0004 и дополняет ADR-0005 без изменения обычных provenance gates.
Существующие сигнатуры и обычный loader сохранены; переход выполняется явно.

## Последствия и проверка

Свежий серверный каталог доступен без Apple products. Он сохраняет ID, цены,
порядок и дубли; перед checkout выбранная строка проверяется повторно.
Backend подтверждает оплату и доступ. Модульные contract probes и template gate
проверяют новую ветку и старые вызовы без настоящих платежей.
