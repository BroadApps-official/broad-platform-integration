# Автоматическая проверка и исправление

Единый reviewer проверяет выбранную цель: четыре модуля и integration в режиме
platform либо один host app в режиме app.

```bash
bash Scripts/agent_review_and_fix.sh platform --doctor
bash Scripts/agent_review_and_fix.sh platform
bash Scripts/agent_review_and_fix.sh app "/path/to/MyApp" --scheme MyApp
```

Явные режимы только проверяют. Для минимального исправления добавьте --fix.
Старый вызов без аргументов или с run сохраняет исправление платформы.
Обычный Run в Xcode не запускает reviewer.

[Полная инструкция: входы, области, отчёт и exit codes →](AgentReview.md)

Wrapper читает каталог владельцев, запускает независимые проверки, передаёт их
логи одному агенту и формирует Markdown из структурированного ответа. После
--fix проверки повторяются. PASS возможен только при успешных проверках и
отсутствии открытых замечаний; ISSUES/BLOCKED не превращается в PASS сборки.
Исправления в модуле не выдаются за проверенную интеграцию локального кандидата:
integration gate собирает точные опубликованные версии каталога.

App-отчёты остаются внутри app .build; исторические platform reports не
перезаписываются. Проверка не выполняет настоящие платежи и не создаёт unit
tests или test targets. Внутри уже открытого агента выполняйте prompt/gates
непосредственно, не запускайте этот wrapper рекурсивно.
