# Отчёты автоматического агента

Команда `./Scripts/agent_review_and_fix.sh` сохраняет последний успешный ответ
Codex в `latest.md`. Если сам Codex аварийно завершился, его незавершённый ответ
может остаться в `latest.pending.md` для диагностики.

Эти runtime-отчёты не заменяют семь snapshot-bound handoff reports. Они нужны,
чтобы разработчик сразу видел, что агент проверил, нашёл и исправил.

Финальный `latest.md` появляется только после независимого внешнего
`Scripts/agent_gate.sh`. Wrapper добавляет его результат в конец отчёта.
