# Исторические отчёты автоматического агента

Файлы этой папки сохраняют результаты прежних запусков. Дата, версия и старые
продуктовые правила в них не подтверждают текущее состояние платформы.

Новый единый reviewer сохраняет отчёт локально в выбранной цели:
- platform: .build/AgentReview/platform/latest.md;
- app: .build/AgentReview/app/latest.md.

[Единый запуск и статусы →](../../Documentation/AgentReview.md).
App-specific результаты не добавляются в публичный integration repository.
