# Автоматическая проверка и исправление BroadApps iOS Platform

Ты работаешь в корне `BroadAppsIOSPlatform`. Полностью соблюдай корневой
`AGENTS.md`.

Цель: самостоятельно проверить локальную платформу, исправить найденные
platform-owned проблемы и оставить разработчику честный, понятный отчёт.

По решению руководства этот Codex-запуск имеет `danger-full-access` к Mac. Это
нужно для полноценной работы Xcode и CoreSimulatorService. Полный доступ не
расширяет scope: изменять можно только `BroadAppsIOSPlatform`.

Платформа и example предназначены только для iPhone. Не добавляй iPad, Mac,
Mac Catalyst или visionOS targets/configurations.

На macOS для каждого самостоятельного поиска явно используй
`/opt/homebrew/bin/rg`, если он доступен. Не вызывай временную копию из
`codex-path`: её может блокировать Gatekeeper.

1. Прочитай `README.md`, `AgentChecks/STATUS.md` и документацию, относящуюся к
   проверяемым компонентам. Если существует
   `.build/AgentAutomation/gate.log`, прочитай его: это результат последней
   независимой wrapper-проверки и причина нового correction attempt.
2. Запусти `bash Scripts/agent_gate.sh`. Это полный local engineering gate,
   Xcode build matrix и обе compile-only live Adapty configurations.
3. Если gate содержит ошибку, найди первопричину.
4. Внеси минимальное исправление только внутри `BroadAppsIOSPlatform`.
5. Не изменяй reference-проекты, Git history, test policy и рабочие tracked
   Adapty configs. Не выполняй реальные платежи.
6. Не отключай проверки, не скрывай ошибки и не подменяй PASS текстом.
7. После Swift-правок запусти `bash Scripts/format.sh`.
8. Повторяй `bash Scripts/agent_gate.sh`, пока он не пройдёт полностью.
9. Не запускай `Scripts/agent_review_and_fix.sh`: его уже запустил разработчик.

Финальный ответ напиши по-русски в Markdown с точными разделами:

## Итог

`PASS` либо `BLOCKED` и одно простое предложение почему.

## Что проверил

## Что нашёл

## Что исправил

Если правок не было, прямо напиши: `Правки не потребовались`.

## Изменённые файлы

Укажи каждый файл и смысл изменения либо `Нет`.

Не вставляй абсолютные machine-specific пути и Markdown links. Используй
только относительные пути от корня платформы.

## Команды и результаты

Укажи финальный статус `bash Scripts/agent_gate.sh`. После ответа wrapper ещё
раз независимо запустит тот же gate и добавит результат в отчёт.

## Что осталось

Только реальные ограничения или `Ничего в рамках локального agent gate`.
