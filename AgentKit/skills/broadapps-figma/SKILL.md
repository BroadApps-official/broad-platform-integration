# Figma без MCP: спецификации и экспорт

Разработчик дал ссылку на Figma. MCP не нужен: открой файл в браузере, где он вошёл в
Figma (computer use или браузер агента). Файл обычно view-only — этого достаточно.

## 1. Найти раздел

1. Открой ссылку, закрой баннер cookies (отказ от необязательных).
2. `Shift+1` — весь холст; выдели нужную секцию (например «onboarding + paywall»),
   `Shift+2` — приблизить к ней. Кадры экранов и отдельные кадры картинок («onb img1»,
   «paywall img») лежат рядом.
3. Без выделения панель справа показывает стили файла: текстовые стили (размер/вес/
   межстрочный) и цвета — с них начинается дизайн-система.

## 2. Снять спецификации

- Выдели кадр экрана — ширина кадра (обычно 402 или 393) = `LayoutScale.designWidth`.
- `Cmd+клик` по тексту → панель: Font, Weight, Size, Line height, Letter spacing, цвет
  (`txt/primary 60` = цвет с прозрачностью).
- `Shift+Enter` — выделить родителя: auto-layout покажет Flow, Gap, Padding, Radius,
  заливку и обводку. Так собираются отступы между блоками без линейки.
- Кнопки и строки — компоненты (`btn`, `icon btn`): размер, радиус, градиент.
- Жёлтые заметки рядом с кадрами — требования («крестик через N секунд»); сверь их с
  чек-листом Kaiten и спроси, если противоречат.

Запиши значения в токены (`AppTokens`), не в код экранов.

## 3. Выгрузить картинки в 6x

1. Выдели кадр картинки или слой изображения (для картинки на белом фоне — сам слой,
   тогда сохранится прозрачность).
2. Панель Export → `+` → поле масштаба `6x` → формат PNG → «Export …». Файл попадёт в
   Загрузки. Настройка экспорта сбрасывается при смене слоя — ставь `6x` заново и
   проверяй поле перед нажатием (иначе клавиши уйдут на холст).
3. В проект: уменьши до `@3x` (`sips --resampleWidth`), фото — JPEG 85–90%, картинки с
   прозрачностью — PNG. Имя ассета по смыслу (`onboarding1`, `paywallBackground`).
4. Иконка приложения без альфа-канала.

## 4. Проверить себя

Собери экран, сделай скриншот в симуляторе того же устройства, что кадр Figma
(402 → iPhone 17 Pro), и сравни положения заголовка, кнопки и ссылок с кадром.
